## 操作

ソートスティックを手に持ち、整列したい入れ物を **殴り** ます。
入れ物を開く必要はありません。

整列が終わると「ポン」という音が鳴り、チャットに結果が表示されます。

```text
中身を整列しました。（5 種類 / 12 スタック）
```

## 整列できる入れ物

| 整列できる | 整列できない |
| --- | --- |
| チェスト | エンダーチェスト |
| トラップチェスト | ホッパー、ドロッパー、ディスペンサー |
| 銅のチェスト | かまど、溶鉱炉、燻製器 |
| 樽 | その他の入れ物以外のブロック |
| シュルカーボックス（全色） | |

整列できないブロックを殴ると「このブロックは整列できません。」と表示されます。

## まとめ方と並び順

### まとめ方

- 「同じアイテム」は、種類だけでなく、名前・エンチャント・耐久値などもすべて同じものです。名前を付けた剣と付けていない剣は、別々のままです。
- スタックできないアイテム（道具・防具など）は 1 個ずつのまま並びます。

### 並び順

1. **アイテムの種類** ごとにまとまります。並び順はアイテムの内部名（`minecraft:dirt` など）のアルファベット順です。日本語の表示名の順ではありません。
2. 同じ種類の中では、**金床で付けた名前** の順に並びます。名前の無いものが先です。
3. それでも同じなら、**個数の多い** スタックが先になります。

## 注意

- ソートスティックを持っている間は、殴ってもブロックは **壊れません**。入れ物を誤って壊さないためです。
- 入れ物を開いていなくても整列できます。他のプレイヤーが開いている最中に整列すると、その人の画面の表示も入れ替わります。
