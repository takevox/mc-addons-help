**作業台** でクラフトします。

## ソートスティック

| |
| --- |
| チェスト |
| 棒 |

![作業台でソートスティックをクラフトする画面](../../../assets/screenshots/sortstick/recipe-sort-stick.png)

- 材料: チェスト ×1、棒 ×1（チェストを上、棒を下に縦に並べる）
- できあがり: ソートスティック ×1
- レシピ本への表示: チェストを手に入れると表示されます。
