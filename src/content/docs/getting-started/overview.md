mc-addons は、Minecraft 統合版（Bedrock Edition）向けのアドオン集です。
このヘルプでは、アドオンごとに章を分けて、アイテムのレシピと使い方を説明します。

## 収録アドオン

| アドオン | バージョン | 追加アイテム |
| --- | --- | --- |
| [ブックマーク](/bookmark/) | 1.0.16 | ブックマーク、転送板 |
| [拡張経験値システム](/eeps/) | 1.0.12 | 空の経験値ボトル、封入済み経験値ボトル、経験値ボード（小・中・大） |
| [ソートスティック](/sortstick/) | 1.0.4 | ソートスティック |
| [Enhanced Recipes](/enhancedrecipes/) | 1.0.8 | なし（レシピのみ追加） |
| [墓石](/gravestone/) | 1.2.0 | 祭壇（墓石本体はクラフト不可） |
| [リサイクラー](/recycler/) | 1.1.0 | リサイクラー |

## 各章の構成

アドオンごとの章は、おおむね次の順で並んでいます。

1. **概要** … そのアドオンで何ができるか
2. **レシピ** … クラフトに必要な材料と並べ方
3. **機能ごとの使い方** … 操作方法と、うまくいかないときの条件
4. **メッセージ一覧** … チャットに表示されるメッセージの意味と対処

## 操作の呼び方

このヘルプでは、操作を次のように呼びます。

| 呼び方 | PC（キーボード・マウス） | タッチ操作 | コントローラー |
| --- | --- | --- | --- |
| 殴る（左クリック） | 左クリック | ブロックを長押し（壊す操作） | 右トリガー（RT / R2） |
| 使う（右クリック） | 右クリック | ブロックをタップ / 使用ボタン | 左トリガー（LT / L2） |
| スニーク | Shift | スニークボタン | 右スティック押し込み |

:::note
キー割り当てを変更している場合は、ご自身の設定に読み替えてください。
:::
