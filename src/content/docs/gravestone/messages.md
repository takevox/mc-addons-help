## チャット

| メッセージ | 意味 |
| --- | --- |
| (X,Y,Z) に墓石を設置しました。 | 死亡時に墓石が設置された |
| 死亡地点が設置に適さなかったため（溶岩、または地面が見つからない）、持ち物はそのまま残りました。 | 死んだ場所や設置先が溶岩、または地面が見つからなかった。[設置できないとき](/gravestone/grave/#設置できないとき) |
| この墓石はまだ保護されています。残り保護期間: Nday Mhour（保護が切れるまでは本人のみ開けます）。 | 保護中の他人の墓石を使おう/壊そうとした |
| N を取り出しました。 | 墓石の GUI でアイテムを取り出した |
| 墓石は空になり、崩れて消えました。 | 墓石の中身を全部取り出した |
| 墓石が破壊され、内容が飛散しました！ | 保護の切れた墓石を壊した |
| 祭壇を設置しました。 | 祭壇を設置した |
| 祭壇を回収しました。 | 祭壇を壊した |
| そこには祭壇を設置できません。 | 置こうとした場所がふさがっていた |
| エメラルドを捧げました。あなたの保護状態が延長されました（残り: Nday Mhour）。 | 祭壇にエメラルドで殴りかかった |

## HUD（アクションバー）

祭壇にクロスヘアを合わせている間に表示されます。

| 表示 | 意味 |
| --- | --- |
| 保護期間: Nday Mhour | 自分の死亡時保護状態が残っている |
| エメラルドを捧げよ | 自分の死亡時保護状態がない |

赤字の `[GRAVESTONE] エラー` は想定外の問題です。[動作確認とトラブルシューティング](/getting-started/diagnostics/) を見てください。
