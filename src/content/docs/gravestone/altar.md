祭壇は、エメラルドを捧げることで、自分が死亡したときにできる墓石に保護期間を付けられるようにするアイテムです。

## 設置する

祭壇を手に持ち、ブロックに向けて **使い** ます。

見た目はバニラのエンダーチェストを流用しますが、祭壇はチェストとして使えません（右クリックしてもバニラの収納 UI は開きません）。

```text
祭壇を設置しました。
```

:::note
置こうとした場所がふさがっていると「そこには祭壇を設置できません。」と表示されます。
:::

## エメラルドを捧げる

エメラルドを持って、設置した祭壇を **殴り** ます。

- エメラルドを 1 個消費し、**殴った本人** の死亡時保護状態がゲーム内 **10 日分** 延長されます。
- すでに残りがある場合は積み上げられます。複数個捧げれば、何段階も延長できます。
- 祭壇自体や献上という行為そのものに期限はありません。

```text
エメラルドを捧げました。あなたの保護状態が延長されました（残り: 12day 4hour）。
```

## 残り保護期間を確認する

祭壇にクロスヘア（視線）を合わせている間、アクションバーに **自分自身** の残り保護期間が表示されます。

| 状態 | 表示 |
| --- | --- |
| 保護状態がある | 保護期間: 2day 1hour |
| 保護状態がない | エメラルドを捧げよ |

この保護状態は祭壇ごとではなく、プレイヤー本人に紐づきます。どの祭壇を殴って延長しても、残りは合算されます。

## 保護の使われ方

死んだ瞬間にこの保護状態が残っていれば（0 より大きければ）、そのときできる墓石に固定の保護期間が一度だけ付きます。詳しくは [墓石の仕組み](/gravestone/grave/#保護される期間) を見てください。

## 回収する

祭壇は誰でも壊せます。壊すとその場に祭壇アイテムが 1 個ドロップします（クリエイティブモードではドロップしません）。

```text
祭壇を回収しました。
```
