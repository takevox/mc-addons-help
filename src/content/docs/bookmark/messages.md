`%s` の部分には、座標や経験値などの値が入ります。

## ブックマーク

| メッセージ | 意味 |
| --- | --- |
| ○○ (X,Y,Z) を記録しました。レベル -1 | 座標を記録した |
| 既に (X,Y,Z) が記録されています。座標は上書きできません。 | 記録済みのブックマークでブロックを殴った。[砥石で消去](/bookmark/clearing/) してから記録する |
| 経験値が足りません。記録にはレベル 1 が必要です。 | レベル 0 で記録しようとした |
| 座標が記録されていません。先にブロックを殴ってください。 | 未記録のブックマークを使った |
| 記録した座標は ○○ にあります。△△ からはテレポートできません。 | 記録したディメンションと今いるディメンションが違う |
| 経験値が足りません。必要 N / 所持 M | テレポートに必要な経験値ポイントが足りない |
| (X,Y,Z) へテレポートしました。経験値 -N | テレポートした |
| 砥石でブックマークの座標を消去しました。 | 座標を消去した |
| このブックマークには座標が記録されていません。砥石を殴ると記録済みの座標を消去できます。 | 未記録のブックマークで砥石を殴った |

## 転送板

| メッセージ | 意味 |
| --- | --- |
| 転送板を設置しました。 | 設置した |
| ここには設置できません。 | 置く場所がふさがっている、または下面に向けた |
| 転送板にブックマークを埋め込みました。 | 埋め込んだ |
| この転送板には既にブックマークが埋め込まれています。 | 埋め込み済みの転送板を殴った |
| 座標が記録されていないブックマークは埋め込めません。 | 未記録のブックマークで殴った |
| この転送板にはブックマークが埋め込まれていません。 | 空の転送板を使った |
| 転送板を回収しました。 | 壊して回収した |

## その他

赤字の `[BOOKMARK] エラー` は想定外の問題です。[動作確認とトラブルシューティング](/getting-started/diagnostics/) を見てください。
