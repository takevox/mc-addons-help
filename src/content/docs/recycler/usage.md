## 設置する

リサイクラーを手に持ち、ブロックに向けて **使い** ます。向いた方向（上下左右前後）がそのままリサイクラーの正面になります。

```text
リサイクラーを設置しました。
```

見た目はバニラのディスペンサーを流用しますが、印の無い通常のディスペンサーには一切干渉しません。右クリックしてもバニラの収納 UI は開きません。

:::note
置こうとした場所がふさがっていると「そこにはリサイクラーを設置できません。」と表示されます。
:::

## 革装備を投入する

リサイクルしたい革装備を持って、設置したリサイクラーを **殴り** ます。

- 革装備を 1 個消費し、残り耐久率に応じた個数の革を **正面** にそのまま排出します（コンテナには入りません）。
- 耐久度フル（新品）の革装備を変換したときに得られる個数は、次のとおりです。

| アイテム | 耐久フル時に得られる革 |
| --- | --- |
| 革の帽子 | 4 個 |
| 革のチェストプレート | 7 個 |
| 革のズボン | 6 個 |
| 革のブーツ | 3 個 |

実際に得られる個数は、この数に **残り耐久率**（0〜1）を掛けて切り捨てたものです（最低 1 個）。耐久が減っているほど、得られる革は少なくなります。

```text
3 個に変換しました。
```

:::note
染色した革装備も変換できますが、色の情報は失われ、無着色の革が得られます。
:::

リサイクルできないアイテムを持って攻撃すると、次のように表示されます。

```text
リサイクルできるものを持って攻撃してください。
```

## 確認する

リサイクラーにクロスヘア（視線）を合わせると、アクションバーに「リサイクラー」と表示されます。

## 回収する

リサイクラーは誰でも壊せます。壊すとその場にリサイクラーアイテムが 1 個ドロップします（クリエイティブモードではドロップしません）。

```text
リサイクラーを回収しました。
```
