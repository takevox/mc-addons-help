| メッセージ | 意味 |
| --- | --- |
| リサイクラーを設置しました。 | リサイクラーを設置した |
| リサイクラーを回収しました。 | リサイクラーを壊した |
| そこにはリサイクラーを設置できません。 | 置こうとした場所がふさがっていた |
| リサイクルできるものを持って攻撃してください。 | 変換対象でないアイテムを持って攻撃した |
| N 個に変換しました。 | 革装備を投入し、革が排出された |

## HUD（アクションバー）

リサイクラーにクロスヘアを合わせている間、「リサイクラー」と表示されます。

赤字の `[RECYCLER] エラー` は想定外の問題です。[動作確認とトラブルシューティング](/getting-started/diagnostics/) を見てください。
