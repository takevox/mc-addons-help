## 経験値ボトル

| メッセージ | 意味 |
| --- | --- |
| 経験値 N ポイントをボトルに封入しました。 | 経験値を詰めた |
| 封入できる経験値がありません。 | 経験値が 0 のときに空のボトルを使った |
| ボトルから経験値 N ポイントを取り出しました。 | 中身を全部取り出した |
| 経験値が上限のため N ポイントだけ取り出しました。ボトルの残り M ポイント | 一部だけ取り出した。残りはボトルに入ったまま |
| 経験値が上限のため取り出せません。 | 自分の経験値がこれ以上増やせない |

## 経験値ボード

| メッセージ | 意味 |
| --- | --- |
| 経験値ボード（N ポイント単位）を設置しました。 | 設置した |
| ここには設置できません。 | 置く場所がふさがっている、または下面に向けた |
| 経験値 N ポイントを預けました。残高 M ポイント | 預けた |
| 預ける経験値がありません。残高 N ポイント | 経験値が 0 のときに殴った |
| 経験値 N ポイントを引き出しました。残高 M ポイント | 引き出した |
| 預けている経験値がありません。 | 残高が 0 のときに使った |
| 経験値が上限のため引き出せません。残高 N ポイント | 自分の経験値がこれ以上増やせない |
| 経験値ボードを回収するにはスニークしながら壊してください。 | スニークせずに壊そうとした |
| 経験値ボードを回収しました。 | 回収した |
