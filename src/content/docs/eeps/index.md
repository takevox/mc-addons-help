拡張経験値システム（Enhanced Experience Point System、略称 EEPS）は、経験値を持ち運んだり貯金したりできるアドオンです。

## 追加されるアイテム

| アイテム | 説明 | スタック |
| --- | --- | --- |
| 空の経験値ボトル | 使うと、自分の経験値を最大 1,000 ポイント詰められる | 64 |
| 封入済み経験値ボトル | 経験値が詰まったボトル。使うと中身を取り出せる | 1 |
| 経験値ボード | 1 回の操作で 100 ポイントずつ預け入れ・引き出しできる看板 | 16 |
| 中型経験値ボード | 1 回の操作で 1,000 ポイントずつ | 16 |
| 大型経験値ボード | 1 回の操作で 10,000 ポイントずつ | 16 |

## ボトルとボードの違い

| | 経験値ボトル | 経験値ボード |
| --- | --- | --- |
| 経験値の置き場所 | ボトル（アイテム）の中 | 自分専用の預け入れ残高 |
| 容量 | 1 本あたり最大 1,000 ポイント | 上限なし |
| 他の人に渡せるか | 渡せる（ボトルを渡すだけ） | 渡せない（残高は本人だけのもの） |
| 向いている使い方 | 持ち運び・受け渡し | 拠点での貯金 |
