## アドオン一覧

| アドオン | できること |
| --- | --- |
| [ブックマーク](/bookmark/) | ブロックを殴って座標を記録し、経験値を払ってその場所へテレポートする。転送板を置けば誰でも使えるテレポート地点になる |
| [拡張経験値システム](/eeps/) | 経験値をボトルに詰めて持ち運んだり、経験値ボードに預けて貯金したりできる |
| [ソートスティック](/sortstick/) | チェストや樽を殴るだけで、中身をまとめて並べ替える |
| [Enhanced Recipes](/enhancedrecipes/) | バニラにないクラフトレシピを追加する（腐った肉 → 革） |
| [墓石](/gravestone/) | 死亡時に保護付きの墓石を設置し、持ち物を失わないようにする |
| [リサイクラー](/recycler/) | 使い古した革装備を攻撃して革に戻す |

## 困ったときは

- アドオンが動いているか確かめたい → [動作確認とトラブルシューティング](/getting-started/diagnostics/)
- 経験値の「ポイント」と「レベル」の違いが分からない → [経験値ポイントとレベル](/getting-started/experience/)
